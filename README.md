# The Watcher: Cosmic Observatory

An immersive 3D universe you can explore in the browser, and then see through the eyes of the
being who has been watching it all along. Static site, no backend, no paid services.

## Run it

```bash
npm install
npm run dev
```

Then open the printed local address. Node 22 or newer is recommended.

```bash
npm run build     # type-checks, then writes the static site to dist/
npm run preview   # serves dist/ locally
```

## Using it

| Do this | To |
| --- | --- |
| Drag | Orbit (or look around, in his eyes) |
| Right-drag or Shift-drag | Pan |
| Scroll, or + and - | Zoom (in his eyes, change the lens) |
| Hold Alt | Fine control for drag, pan, zoom and keys |
| Hold Shift | Move faster with the keys |
| W A S D, Q, E | Fly freely |
| Arrow keys | Orbit |
| [ and ] | Previous or next world |
| 1, 2, 3 | Observer, his eyes, planetary |
| R | Recentre |
| G | Turn his gaze to the selected world |
| M, O, ? | Atlas, settings, the list of keys |
| V | His voice on or off |
| H | Hide the interface |
| F | Fullscreen |
| Click a world | Fly to it |
| Click the Watcher | Choose: approach, or see through his eyes |
| Drag, scroll or fly mid-flight | Take the camera back (a plain click does not) |
| Esc | Close what is open, then return to the overview |

The zoom rail appears on the right when you zoom and fades by itself. Rest the pointer on the right
edge to bring it back and drag it. Drag and zoom speed are in Settings, and are remembered. Add
`?world=jupiter` to the address to open on a world; **Copy link** on any world does this for you.

The bottom control switches between Observer, His eyes and Planetary. Selecting a world never
changes what the Watcher is observing; use **Turn his gaze here** on a world to do that.

He speaks: an opening line, reactions when you approach him, look through his eyes or reach Earth,
Titan or Vormir, and quiet thoughts while you explore. Volume, his voice and subtitles are in
Settings. The lines and their timings are in `src/voice/lines.ts`.

## Deploying

Push to `main` on GitHub, then set **Settings > Pages > Source** to **GitHub Actions**. The workflow
in `.github/workflows/deploy.yml` builds and publishes the site. Asset paths are relative, so it
works under any repository name.

## Replacing the character

Put a GLB at `public/assets/characters/watcher.glb`. It needs a node named `Head`, and optionally
`Eye_L`, `Eye_R` and `Halo_A` to `Halo_C` (+Z forward, Y up, character about 8 units tall). See
`docs/ARCHITECTURE.md`. The current model is an original design, a hooded colossus with a porcelain
mask and an astrolabe halo, generated by `npm run bake:watcher`.

## Known limitations

- Browsers hold back sound until the first click or key press, so a first-time visitor may need one
  click to hear the opening. The title says so when that happens.
- Needs WebGL 2. Designed for desktop browsers; touch input is not tuned, and there is no pinch zoom.
- Changing the graphics level rebuilds the renderer and returns you to the overview.
- Measured on an Intel UHD integrated GPU only. Before the remaster, at 1280x720: about 32 fps on
  Low, 27 on Medium and 16 on High. After it: 54 fps on Low at 896x503. Other levels and the RTX 4050
  have not been re-measured.
- Low has no anti-aliasing, so the gold edges of the figure look stepped up close.
- The character is a static sculpture with head, halo and float motion, not a skinned rig.
- Planets do not shadow each other, and world positions are composed rather than orbital.
